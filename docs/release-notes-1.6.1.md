## Finde dein Auto versteht ACRISS-Codes besser

- **Angefangene Codes:** `CD` findet CDMR und CDAR, `C` alle Kompaktklassen.
  Großgeschrieben und höchstens vier Zeichen gilt als Code, alles andere als
  Modellname.
- **Vorschläge:** Nach der ersten Suche schlägt das Feld jeden Code vor, den
  die Stationen gerade anbieten, mit Modell daneben, und dazu die Modellnamen.
- **Das Auto als Bild:** Unter dem Feld steht, welches Fahrzeug zum
  Eingegebenen passt. Bei einem Code weiß man so, was man vor sich hat.

## README

Zwei neue Bilder, Rangliste mit Karte und Finde dein Auto, aufgenommen an
einem echten Lauf über 64 Stationen in Nordrhein-Westfalen. Eine neue Zeile
in „Was TRACKER beantwortet": VW Golf, 3 Tage, 148,98 € an der günstigsten
Station gegen 345,98 € an der teuersten.
